# ПВА 2.0 «Центр-инвест Бизнес»

Собранное мобильное веб-приложение интернет-банка для юридических лиц.
Исходный код — в приватном репозитории.

Данные банка запрашиваются только при наличии ключа доступа к сервису:
без него приложение ничего не показывает. Ключ хранится на устройстве
пользователя и в этом репозитории не содержится.
